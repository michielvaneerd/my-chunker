# How to Create Lists in Markdown

**Unordered Lists:**
- Item 1
- Item 2
  - Nested item
  - Another nested item
- Item 3

**Ordered Lists:**
1. First item
2. Second item
   1. Nested numbered item
   2. Another nested item
3. Third item

**Mixed Lists:**
1. Ordered item
   - Unordered sub-item
   - Another sub-item
2. Another ordered item

**Task Lists:**
- [x] Completed task
- [ ] Pending task
- [x] ~~Completed and crossed out~~
